# Локализация Android-приложения

Здесь лежат только переводы. Вёрстка, цвета, темы и иконки остались в
`src/main/res` — так проще править тексты, не задевая всё остальное.

Папка подключена как дополнительный каталог ресурсов в `app/build.gradle.kts`:

```kotlin
sourceSets {
    getByName("main") {
        res.srcDirs("src/main/res", "localization")
    }
}
```

## Раскладка

Android сам определяет язык по имени папки, поэтому структура внутри —
стандартная и менять её нельзя:

| Папка | Язык |
| --- | --- |
| `values/` | английский, он же запасной для всех неперечисленных языков |
| `values-ru/` | русский |

## Как добавить язык

1. Создать папку `values-<код>` — например `values-uk`, `values-de`, `values-kk`.
   Код языка — двухбуквенный по ISO 639-1.
2. Скопировать в неё `values/strings.xml` и перевести значения.
   **Атрибуты `name` менять нельзя** — по ним код находит строку.
3. Пересобрать приложение. Ничего регистрировать больше не нужно.

Если строки в новом файле не хватает, Android возьмёт её из `values/`,
поэтому неполный перевод приложение не ломает.

## Согласованность с десктопной версией

Формулировки берутся из `ui/i18n/ru.json` и `ui/i18n/en.json` в корне
репозитория, чтобы Android и десктоп говорили одинаково. Отличаются только
строки, где путь настройки в Telegram для Android другой, чем в Telegram
Desktop, и те, что относятся к особенностям платформы — например
предупреждение про порты ниже 1024.

## Выбор языка пользователем

В настройках приложения есть пункт «Язык»: «Как в системе», «Русский»,
«English». Реализовано через системный `LocaleManager.setApplicationLocales`
(Android 13+). На более старых версиях приложение следует языку системы.
